# Monster Glow Up Spa

A cozy, spooky-cute co-op game for Roblox, made by **Polar Paws Studio**.

Monsters check in for a night of pampering.
Grab a friend, clock in with Mortimer the sleepy reaper cat, and send every guest home glowing.

## Status

In development.
Coming to Roblox in October 2026.
